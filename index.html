Near Memory Compute (NMC) Accelerator for CMS L1 Scouting 2025
OpenLab Summer Student · Advisor: Thomas Owen James · CERN

Investigated CXL-enabled, FPGA-based NMC accelerators for CMS L1 Data Scouting. Benchmarked physics-driven workloads like jet clustering on Micron’s platform and explored scalability to optimize real-time event reconstruction.

Accelerating Zero Knowledge Proofs on Multithreaded AMD CPUs 2024
Research Intern · Advisors: Dr. Alireza Kaviani (AMD), Dr. Shantanu H. Joshi (UCLA)

Accelerated core cryptographic functions (hashing and pairing) on AMD EPYC™ processors. Optimized Multiscalar Multiplication using SIMD, loop unrolling, and cache alignment to significantly improve memory access and processing time.

Hardware-Algorithm Co-Optimization for Transformer Accelerators 2024 – 2025
NUST Chip Design Centre (NCDC) · Advisors: Dr. Waqar Ahmad

Designing resource-efficient architectures for Transformer Neural Networks. Investigating sparse attention, mixed-precision computations, and approximate computing to develop architectures that reduce latency through hardware-level memory optimizations.
